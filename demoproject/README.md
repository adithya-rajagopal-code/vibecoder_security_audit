# VibeShop — E-Commerce Microservice

A lightweight backend API service developed for the VibeShop demonstration.

## Features

- Product catalog management (`products.py`)
- User profile search & lookup (`users.py`)
- Order management and account retrieval (`account.py`)
- Secure database interaction utilities (`safe_queries.py`)
- Centralized configuration (`config.py`)

## Running the Service

```bash
pip install -r requirements.txt
python app.py
```
